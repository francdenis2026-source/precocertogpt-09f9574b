# Nota de implementação

O refinamento desta etapa é intencionalmente restrito aos seletores `.pc-header*` e `.pc-dialog*`, todos sob `.pc-home`. Ele não redefine tokens globais, cards, seções, footer ou lógica da aplicação. A folha separada existe para manter o ajuste isolado e reversível nesta etapa; uma consolidação futura pode mover estas regras para `HomePremium.css` sem alterar o resultado visual.
