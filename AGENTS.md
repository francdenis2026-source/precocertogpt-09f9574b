# Codex project instructions

## UI/UX Pro Max

This repository is prepared to use UI UX Pro Max with Codex.

- For tasks that change UI, UX, layout, typography, colors, responsive behavior, accessibility, animation, navigation, cards, forms, dashboards, product listings, comparison screens, or visual polish, use the project skill at `.agents/skills/ui-ux-pro-max/SKILL.md`.
- If `.agents/skills/ui-ux-pro-max/scripts/search.py` is not present in the current checkout, run `npm run uipro:codex` from the repository root before doing UI/UX work. This refreshes the complete project-local UI UX Pro Max skill using the official CLI.
- After installation, prefer the local searchable design database and generate a design system before broad redesign work.
- Keep the application language in Portuguese unless the user explicitly asks otherwise.
- Preserve existing product/business logic unless the requested UI/UX change requires a functional adjustment.
- Validate responsive layouts, accessibility, light/dark contrast, loading/error states, and keyboard/touch interaction before finishing UI work.
